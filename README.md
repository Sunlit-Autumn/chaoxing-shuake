# 学习通自动刷课脚本

一个 Tampermonkey 用户脚本，用于自动完成超星学习通章节页的视频 / 音频任务点。

不是通用框架，只解决一件事：**打开章节页，剩下的它自己跑完**。

---

## 特性

- **音视频统一接管** —— 同时处理 `<video>` 和 `<audio>`，自动识别 video.js 生成的真实播放器，跳过 `auditionAudio` 这类空壳元素
- **递归穿透 iframe** —— 学习通把每个附件放在独立 iframe 里，脚本从顶层窗口递归查找三层内的所有媒体元素，统一调度
- **严格串行播放** —— 同一时刻只允许一个播放器运行，其余强制暂停。这一条很关键，多个音频同时播放会触发平台风控
- **等上报确认再切节** —— 媒体播完后停留 15 秒，等服务端记录进度，再跳下一节。避免"进度走完但任务点没打勾"
- **纯图文章节自动跳过** —— 页面没有任何 `<audio>/<video>` 时，停留 15 秒后直接切下一节
- **自动跳过已完成节点** —— 按目录的完成标记向后查找下一个未完成任务点
- **2 倍速 + 静音 + 防暂停** —— 前端把倍速改回去会自动修正，被暂停会自动恢复

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/)（或 Violentmonkey）

2. **Edge 用户注意**：137 版本起，用户脚本需要单独授权

   打开 `edge://extensions` → 找到 Tampermonkey → 点「详细信息」 → 打开 **「允许用户脚本」** 开关

   不开这一项，脚本装了也不会执行。这是最常见的卡点。

3. 安装脚本，二选一：

   - 把 `chaoxing.user.js` 拖进浏览器窗口，Tampermonkey 会拦截并弹出安装页
   - 或者在 Tampermonkey 面板 → 实用工具 → 「从 URL 安装」填入脚本地址

4. 装完后**完全退出浏览器再重开**（权限变更需要重启才对新脚本生效）

## 使用

打开学习通的章节学习页：

```
https://mooc1.chaoxing.com/mycourse/studentstudy?chapterId=...&courseId=...&clazzid=...
```

脚本会自动：

1. 定位到第一个未完成的任务点
2. 以 2 倍速静音播放
3. 同章节内多个任务点按顺序依次播完
4. 每个任务点播完后停留 15 秒等待上报
5. 全部完成后跳到下一节，循环

**不需要点击任何按钮。**

### 验证是否生效

按 F12 打开 Console，筛选框输入 `[cx]`，应该看到：

```
[cx] injected v5.3 (top-frame only, recursive, dwell for no-media units)
[cx] catalog nodes = 122 | done = 6
[cx] media count ? -> 2
[cx] bind AUDIO audio_html5_api 71s
```

## 调试接口

脚本在页面 `window` 上挂了一组控制台函数：

| 函数 | 作用 |
|---|---|
| `cxAll()` | 列出页面（含 iframe）中所有 `<video>/<audio>`，附 `duration`、`readyState`、`inFrame`、`src` |
| `cxStatus()` | 列出当前受管的播放器状态，含「是否已判定播完」 |
| `cxScan()` | 列出目录所有节点及其完成状态 |
| `cxNext()` | 手动跳到下一个未完成节点 |
| `cxJump(n)` | 跳到目录第 n 个节点 |
| `cxPause()` | 立即暂停所有播放器（风控弹窗时用） |

出问题时优先跑 `cxAll()`，输出基本能定位所有媒体识别问题。

## 工作原理

### 页面结构

学习通的章节页由三部分组成：

```
主文档（目录树 + 内容容器）
  └── iframe × N（每个附件一个：视频 / 音频 / 文档 / 图片）
```

任务是「任务点」，每个附件对应一个任务点，完成条件是**观看时长 ≥ 总时长的 90%**，由播放器周期性向服务端上报。

### 关键设计

**① 只让顶层窗口执行**

油猴的 `@match *://*.chaoxing.com/*` 会在每个 frame 各注入一份。如果每个 iframe 的实例都去播放自己的媒体，结果是所有附件同时播放——这既不符合正常行为，也会被判定异常。

所以脚本第一件事是判断自己是否在顶层：

```js
if (window.top !== window) return;
```

子 frame 的实例直接退出，什么都不做。

**② 顶层递归收集媒体**

```js
root.querySelectorAll('video, audio')
  → 遍历 iframe → iframe.contentDocument 递归（最多 3 层）
```

同源 iframe 可以直接访问 `contentDocument`。跨域的被跳过。

**③ 串行调度**

每 1.5 秒扫描一次，选出「第一个未播完的媒体」作为当前播放对象，其余全部 `pause()`。

**④ 播完后等上报**

服务端记录进度不是瞬时的。媒体播完立刻切节，最后一次上报可能还没落地，任务点不会打勾。所以固定留 15 秒窗口。

## 已知限制

- **只在旧版章节页测试过**（`mooc1.chaoxing.com/mycourse/studentstudy`）。新版 `mooc2-ans.chaoxing.com/mooc2-ans/mycourse/stu` 的 DOM 结构不同，目录选择器可能匹配不上
- **跨域 iframe 内的媒体无法接管**。如果某个附件来自其他域名，`contentDocument` 访问会抛错，该附件不会被自动播放
- **不处理章节测验和作业**。只负责媒体任务点
- **已完成的任务点会被重播**。脚本不读页面的完成标记，只记录本次运行中播过哪些。代价是每个已完成任务点多花半分钟，换取逻辑简单不易错
- **浏览器必须保持打开且不休眠**
